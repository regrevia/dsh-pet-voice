鲸灵设置


    

      朗读默认走微软神经语音（宿主侧 edge-tts 合成，比系统音自然）；没装或失败时自动回退系统语音。
      一次装好：在电脑上运行 plugins/dsh-pet-voice/tts/setup.sh。
      语音识别用浏览器自带的 Web Speech（Chrome / Edge / 安卓可用，iOS 需 Safari 且每次授权）。
      页面必须走 https 或 localhost 才能收音；公网访问请用 cloudflared 之类的隧道。
