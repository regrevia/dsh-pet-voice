# 没有小爱开发者权限时，语音怎么走

> 背景【实测 2026-10-24】：小爱开放平台首页公告——「由于业务调整，即日起，我们将暂时停止
> 开发者的注册服务」。新账号**无法**再注册成为开发者，也就拿不到「新建技能」入口，
> 手机自定义技能这条路被平台闸门挡住（**不是**我们的服务端问题：服务端 + 协议 + 专属会话已就绪）。

## 0. 先花 2 分钟确认你账号还有没有权限

有些早期小米账号已经具备开发者身份，注册关了、老账号仍能进：

1. 用你的小米账号登录 <https://developers.xiaoai.mi.com/>；
2. 看右上「控制台」里有没有「技能开发 / 创建技能」；
3. 能进 → 回到 [xiaoai-skill.md](xiaoai-skill.md) 照表填，之前的工作全部有效；
4. 进不去（提示未注册/无权限）→ 用下面任一条替代路线。

## 1. 最快能用：系统语音助手当「唤醒 + 输入」外壳（零审核，当天可用）

思路：唤醒和转写交给手机自带的语音助手，**对话仍然发生在我们的网页里**，
播报走页面的神经语音（edge-tts，音色可换）。

### iOS（捷径 + Siri）

1. 手机先能打开 `https://<隧道域名>/pet-voice/`（配对过的会记住 cookie）；
2. 捷径 App → 新建捷径「鲸灵」→ 添加操作「打开 URL」→ 填上面的地址 → 存到桌面/主屏；
3. 「嘿 Siri，打开鲸灵」→ 直接进鲸灵页面，页面自带：
   - 唤醒词（默认「鲸灵」「小鲸」，浏览器内识别，Safari 支持有限）；
   - **按住说话**（最稳，走服务器 ASR）；
   - 回复自动朗读（神经语音，失败回退系统语音）。

### Android

小爱同学 / Google 助理的「打开链接」快捷方式同理；Android Chrome 的
`webkitSpeechRecognition` 支持比 iOS Safari 好，页内唤醒词更可用。

### 1.1 语音不自然的问题已经处理了

页面底部「音色」四档（服务端同源，选完记在本机，刷新保持，带「试听这句」）：

| 档位 | 声音 | 语速 | 音高 | 听感 |
| --- | --- | --- | --- | --- |
| `whale`（默认） | zh-CN-XiaoyiNeural | +6% | +8Hz | 清亮少女，贴像素蓝发鲸鱼娘 |
| `genki` | zh-CN-XiaoyiNeural | +16% | +22Hz | 元气，快而高 |
| `gentle` | zh-CN-XiaoxiaoNeural | -4% | -4Hz | 温柔，慢而低 |
| `cool` | zh-CN-XiaoxiaoNeural | -10% | -12Hz | 清冷，更慢更低 |

【实测 2026-10-24】同一句话四档返回字节/哈希全不同（22464/20448/24480/26064 B），
说明 `voice/rate/pitch` 真的下去了；edge-tts 的 zh-CN **女声只有 4 个**
（晓晓/晓伊/晓北/晓妮），所以四档是「2 音色 × 4 韵律」。要四个不同嗓子只能掺方言（不像鲸鱼娘，没掺）。

### 1.2 地址别填错

页面里「加主屏」卡片会显示**当前可用的手机地址**，它读的是 `GET /pet-voice/api/pair`：

```
{"publicBase":"https://<隧道域名>/pet-voice/","source":"tunnel"}
source = tunnel（公网隧道，手机流量也能开） | lan（同一 WiFi） | local（本机，手机打不开）
```

快速隧道（`scripts/tunnel.sh`，匿名 trycloudflare）的域名每次重启都会变，**换域名后卡片会自动读到新的**；
换成命名隧道（`scripts/tunnel.sh --named`，自己的域名 + `~/.dsh/pet-voice/cloudflared.token`）后域名固定，卡片和 App 都不用再改。

### 1.3 好处与代价

- 好处：不需要任何平台审核、不需要资质、今天就能用；唤醒词体验接近「喊一句就进」；
- 代价：不是「小爱同学」本尊的音色与唤醒；网页必须在前台（后台不收音）。

### 1.4 想「不打开页面也能问一句」？

页面的 cookie 在 Safari/Chrome 里是持久的，快捷指令只要「打开 URL」到
`/pet-voice/`，页面自己会继续上次的会话。真要脚本化（例如 iOS「获取 URL 内容」动作），
宿主已有两个带鉴权的入口，**用 cookie，不要把 token 写进 URL**：

```bash
# 让手机念一句（入播报队列，页面在线时会念）
curl -X POST -H "Cookie: pkv_<token前8位>=<token>" -H 'content-type: application/json' \
     -d '{"text":"该喝水了"}' https://<隧道域名>/pet-voice/api/say

# 直接给鲸灵派一句话（落到专属会话，不会打扰电脑上正在看的会话）
curl -X POST -H "Cookie: pkv_<token前8位>=<token>" -H 'content-type: application/json' \
     -d '{"text":"帮我看下 Pet 项目的验证脚本跑得怎么样"}' https://<隧道域名>/pet-voice/api/dispatch
```

token 在 `~/.dsh/pet-voice/token`（0600），配对二维码里已经含它；
**不要**把它贴进任何公开的捷径分享链接。

## 2. 想保留「小爱本尊」的声音：只差一个开发者账号
