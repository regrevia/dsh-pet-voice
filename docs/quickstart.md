# 从零开始：手机上把大肥鱼用起来

假设你现在什么都没有：电脑上刚装好 DSH，插件刚打开，手机也是空的。按下面的顺序做，一次只做一步。

## 1. 手机装上 APK

在电脑浏览器里打开更新页，点下载：

- 更新页：`http://127.0.0.1:<端口>/pet-voice/`
- 直连文件：仓库 `dist/jingling-0.9.24.apk`，或 GitHub Release 里的同一个文件

手机上打开这个 apk。系统会问「允许来自此来源的应用」，允许一次即可。

> 手机和电脑不在一个网里也能装：先用数据线拷、或用网盘传。装完再连。

## 2. 选一种连法

三种连法选一种就行，不用都配。面板里能看到当前选中的那一种。

### A. 同一 WiFi（最省事，只在家里/办公室用）

1. 插件面板 → 连法 → 选「局域网」。
2. 面板会显示一个地址，形如 `http://192.168.x.x:8480/pet-voice/`，旁边有二维码。
3. 手机打开大肥鱼 → 首页「扫码绑定大肥鱼」→ 扫这个码。
4. 状态变成「已连接」就能说话。

局域网这一行如果显示「现在用不了」，是电脑这边的网络拦了：

- 电脑开着 VPN 且 VPN 把本机地址的路由抢走了；
- 电脑防火墙拦了进来的连接（系统设置 → 网络 → 防火墙，允许 DSH 接收入站连接）。

### B. 用自己的服务器（出门、用流量也能用）

需要一台能从公网连上的服务器（VPS），和它的 SSH 私钥。

1. 插件面板 → 「经自己的服务器转发」→ 填三项：账号（如 `ubuntu`）、公网地址（如 `1.2.3.4`）、私钥路径。
2. 点「连上」。看到「已连通」后，面板会给出 `https://<公网地址>:8443/pet-voice/` 的二维码。
3. 手机扫码绑定。

服务器只要满足两条，插件会自动连：SSH 端口能进；服务器上的 sshd 允许 `GatewayPorts clientspecified`（多数 VPS 默认允许，不允许时连上但外网打不开）。

### C. 一根数据线（零配置，最稳）

1. 手机开「开发者选项 → USB 调试」，插上电脑。
2. 电脑终端跑一次：`adb reverse tcp:8480 tcp:8480`（电脑装了 android platform-tools 才有 adb）。
3. 插件面板 → 选「局域网」，把面板给的地址改成 `http://127.0.0.1:8480/pet-voice/`，或者直接把配对链接发到手机。
4. 手机打开大肥鱼 →「设置」→「电脑地址」→ 粘贴整条配对链接 →「保存设置」。

C 的好处是不用管 WiFi、不用服务器、也不怕防火墙。

## 3. 绑定其实只有一步

不管哪种连法，最后都是把**一条配对链接**交给手机。两种给法：

- 扫码：面板上的二维码，手机「扫码绑定大肥鱼」扫它；
- 粘贴：把链接复制到手机，粘进 App 的「电脑地址」，保存。

链接长这样：`https://<地址>/pet-voice/?k=<一串字符>`。里面的 `k=` 就是访问令牌，所以别发到群里。

## 4. 开始说话

- 首页「对话」进去打字，或点麦克风说话。说完停一下（约 1 秒静音）就发出去，不用等固定时长。
- 「开启悬浮窗权限」之后，退到别的应用也能叫它：说唤醒名（默认「大肥鱼」，面板里能改），它就浮出来接话。
- 电脑上看它回话：`~/.dsh/pet-voice/pet-session.json` 里记的会话就是它正在聊的那个。

## 5. 想改它的样子和说话方式

都在插件面板里，手机端不用再动：

| 想改什么 | 面板里的位置 |
| --- | --- |
| 人设、回答长短 | 「人设」「回答长度」 |
| 叫它的名字 | 「唤醒名」 |
| 气泡提示 | 「气泡」开关 |
| 用哪种传输 | 「连法」 |

手机端只有「设置」页那几个：音色、称呼、精灵大小、形象、显示方式、电脑地址。

## 6. 更新

App 里「更多」→ 检查更新，会读 `http://<地址>/pet-voice/api/update`。电脑上的插件把新版本放到更新通道后，手机点一下就升。

## 卡住了看这里

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 状态一直「未绑定」 | 链接没粘全，或令牌对不上 | 重新复制整条链接（含 `?k=` 后面全部字符） |
| 「已连接」但说话没反应 | 电脑侧的对话服务没在跑 | 电脑上看 DSH 窗口是否正常，面板「诊断」里看最后一次请求 |
| 局域网地址打不开 | VPN 抢路由 / 防火墙 | 换数据线连法（上面 C） |
| 服务器连上了但手机打不开 | 服务器 sshd 没开 `GatewayPorts` | 在服务器 `/etc/ssh/sshd_config` 加 `GatewayPorts clientspecified`，重启 sshd |
